IP Address & DNS

How does a device connect to the internet? Every device needs an address to communicate on the internet. A device is identifiable by a unique IP Address to send and receive data. Think of an IP Address like an apartment address, with each device living in a unit. However, addresses are hard to type and remember, so we use a DNS (Domain Name System). This acts as a phonebook. So when you type in Google.com, the DNS looks up the IP Address to connect.
